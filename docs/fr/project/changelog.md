# Journal des modifications

Cette page affiche le fichier `CHANGELOG.md` du dépôt tel quel. Il est
inclus au moment de la construction plutôt que recopié, afin que les notes
publiées ne puissent pas s'écarter des notes réelles.

Les notes de version sont rédigées en anglais, dans un seul fichier, pour
qu'une version ne puisse jamais être décrite de deux façons différentes.

Le format suit [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), et
le projet applique [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
